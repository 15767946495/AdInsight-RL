# Reproduction results

The final review package must include the real files generated by the released
model:

- `submission.jsonl`: exactly 3,108 official-format inference results.
- `submission.manifest.json`: hashes, frozen model revision, and inference
  settings generated by `scripts/run_inference.sh`.

These files are intentionally not fabricated from reference answers. Run the
documented inference command before publishing the final review link, then
commit both generated files to this directory.
